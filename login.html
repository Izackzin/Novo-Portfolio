Área restrita

Entre com o seu token de acesso do GitHub para gerenciar projetos e certificados. Só quem tem permissão no repositório consegue publicar.

Como criar o token
  1. No GitHub, abra Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Clique em Generate new token e escolha o prazo de validade.
  3. Em Repository access, selecione só o repositório do portfólio.
  4. Em Permissions → Repository permissions, defina Contents como Read and write.
  5. Gere o token, copie e cole aqui. Ele aparece uma vez só.
